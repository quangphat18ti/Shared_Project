## 4 Core Features
1. Agent: Agent to work on development tasks together with AI
    - Kiểu giao task cho AI.
2. Chat: Hỏi các câu hỏi về code. 
3. Edit: Chỉnh 1 code section trong file hiện tại. 
4. Autocomplete: Inline code suggestions.

### Agent - 3 modes: Chat, Plan, Agent
- **Chat**: thảo luận mà không thay đổi code. 
- **Plan**: Understand Codebase, Bug investigation, planning to implement. (Read-Only)
- **Agent**: Implementing features, fixing bugs, running tests and commands.
